Detour for OpenWrt

@VERSION@

Policy-based routing for a home router: which traffic goes through a VPN, which goes directly, which is blocked. Failover between VPN exits and a kill-switch. A LuCI section, Services → Detour.

Install

On the router (OpenWrt 25.12 or a snapshot, apk), over SSH:

wget -qO- @FEED_URL@/install.sh | sh

The script adds this feed and its signing key, replaces dnsmasq with dnsmasq-full and installs detour and luci-app-detour. Run it again to upgrade, or use apk upgrade detour luci-app-detour.

Install by hand

  1. The signing key and the feed: 
    wget -O /etc/apk/keys/detour.pem @FEED_URL@/detour.pem
echo @FEED_URL@/packages.adb >> /etc/apk/repositories.d/customfeeds.list
apk update
  2. dnsmasq-full instead of dnsmasq (skip if it is installed already). While dnsmasq is away the router has no DNS, so download it first or point /tmp/resolv.conf at your provider's servers for the swap: 
    apk del dnsmasq && apk add dnsmasq-full
  3. Detour: 
    apk add detour luci-app-detour
